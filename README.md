# Midwest

A Claude skill that gives it to you straight. It says what's going on, what it means, and what to do next, with no tech talk.

## Install

Run these in your terminal:

```
claude plugin marketplace add eancker/midwest
claude plugin install midwest@midwest
```

## Use it

In Claude Code, type `/midwest:midwest`, or say something like "break it down" or "what do I need to do?"
